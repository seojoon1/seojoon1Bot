# 망호봇 (manghobot)

이터널리턴 커뮤니티 / **망호컵 경매 대회**용 디스코드 봇입니다.
이벤트 정시 알림, 플레이어 전적 조회, 메뉴 추천과 함께, 망호컵 백엔드와 연동되는
**경매 배팅 · 참여 등록 · 실시간 채팅 중계** 기능을 제공합니다.

## 주요 기능

| 분류 | 슬래시 명령어 | 설명 |
|------|--------------|------|
| 알림 | `/알림설정` `/알림해제` `/알림목록` | 정시 이벤트(짝수/홀수/나흐마) 5분 전 DM 구독 |
| 전적 | `/정보` | 이터널리턴 API로 닉네임 전적·티어·모스트 조회 |
| 추천 | `/뭐먹지` | 상황/온도/나라/종류 선택 → Gemini가 메뉴 추천 |
| 망호컵 | `/bid` | 팀에 금액 베팅 (`팀장` 역할 전용) |
| 망호컵 | `/참여` | 이터널리턴 닉네임 + 자기어필 등록(모달) |
| 망호컵 | `/참여자목록` | 등록된 참여자 목록 조회 |
| 망호컵 | `/초기화` | 참여자 정보 전체 초기화 (관리자 전용) |
| 중계 | `/중계채널설정` `/중계채널해제` `/중계채널확인` | 실시간 채팅 중계 채널 관리 (관리자 전용) |

### 실시간 채팅 중계
지정한 채널의 일반 메시지를 백엔드 `POST /api/chat`으로 전송해 경매 웹 화면 사이드
패널에 실시간 표시합니다. 봇 메시지·빈 메시지·첨부만 있는 메시지·명령어(`!`)는 제외하며,
메시지는 200자로 잘라 보냅니다.

## 백엔드 연동 API

기능 일부는 외부 망호컵 백엔드(`BACKEND_URL`)와 통신합니다.

| 메서드 | 엔드포인트 | 사용 기능 |
|--------|-----------|----------|
| POST | `/api/bid` | `/bid` |
| POST | `/api/join` | `/참여` |
| GET  | `/api/players` | `/참여자목록` |
| POST | `/api/reset` | `/초기화` |
| POST | `/api/chat` | 채팅 중계 |

## 프로젝트 구조

```
manghobot/
├── main.py            # 전체 기능 봇 진입점 (알림·전적·추천 + 망호컵)
├── manghocup_bot.py   # 망호컵 전용 봇 진입점 (배팅·참여·채팅 중계만)
├── bid.py             # /bid, /참여, /참여자목록, /초기화
├── chat_relay.py      # 채팅 중계 + 중계 채널 관리 명령어
├── food.py            # /뭐먹지 (Gemini 메뉴 추천)
├── config.py          # 환경변수·상수 로딩
├── db.py              # SQLite 초기화 + settings 저장소
├── constants.py       # 이벤트 메시지·캐릭터 이름 테이블
└── requirements.txt
```

`main.py`와 `manghocup_bot.py`는 **같은 봇 토큰**을 사용하므로 동시에 실행할 수 없습니다.
전체 기능이 필요하면 `main.py`, 망호컵 기능만 따로 돌리려면 `manghocup_bot.py`를 실행하세요.

## 설치

```bash
pip install -r requirements.txt
```

> `aiohttp`는 `discord.py`에 포함되어 있어 별도 설치가 필요 없습니다.

## 환경변수 (.env)

프로젝트 루트에 `.env` 파일을 만들고 아래 값을 채웁니다.

```env
# 필수
API_KEY=디스코드_봇_토큰

# 망호컵 백엔드 (미설정 시 http://localhost:8000)
API_URL=http://localhost:8000

# 이터널리턴 API (/정보 명령어)
ER_API_KEY=이터널리턴_API_키

# Gemini API (/뭐먹지 명령어)
GEMINI_API_KEY=제미나이_API_키

# 실시간 채팅 중계 기본 채널 ID (선택 — /중계채널설정으로도 지정 가능)
CHAT_RELAY_CHANNEL_ID=123456789012345678
```

| 변수 | 용도 | 필수 |
|------|------|------|
| `API_KEY` | 디스코드 봇 토큰 | ✅ |
| `API_URL` | 망호컵 백엔드 베이스 URL | ⬜ (기본 localhost:8000) |
| `ER_API_KEY` | 이터널리턴 오픈 API 키 | `/정보` 사용 시 |
| `GEMINI_API_KEY` | Gemini API 키 | `/뭐먹지` 사용 시 |
| `CHAT_RELAY_CHANNEL_ID` | 채팅 중계 기본 채널 | ⬜ |

> 중계 채널은 환경변수 대신 `/중계채널설정` 명령어로 지정하는 것을 권장합니다.
> DB에 저장된 설정이 환경변수보다 우선하며, 봇 재시작 후에도 유지됩니다.

## 실행

```bash
# 전체 기능 봇
python main.py

# 망호컵 전용 봇 (택일 실행)
python manghocup_bot.py
```

슬래시 명령어는 봇 시작 시 동기화됩니다. 글로벌은 반영까지 최대 1시간이 걸리며,
`on_ready`의 `guild_ids`에 등록된 길드는 즉시 반영됩니다.

## 비고
- `message_content` 인텐트가 필요합니다(채팅 중계). 디스코드 개발자 포털에서 활성화하세요.
- `/초기화`, 중계 채널 관리 명령어는 **서버 관리자 권한** 보유자만 사용할 수 있습니다.
- `/bid`는 `팀장` 역할 보유자만 사용할 수 있습니다.
